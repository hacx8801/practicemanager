## An integrated solution for metronome-based instrument practice

This is a rewrite of a similar application originally conceived by the author as a Java application built on the Swing toolkit. This project was made to solve a specific niche in my practice routines for guitar and keyboard: the need to constantly adjust separate metronome and timers quickly becomes tedious at best and distracting at worst. So, I built this small application to automatically step through a structured practice routine and set a specific timer and BPM value for each exercise.

This implementation is written purely in HTML/CSS/JavaScript, and currently only supports locally-stored JSON files as a means of configuring a practice routine. However, inserting/editing/removing exercises is provided in-app, meaning an understanding of JSON formatting is not required to use this app, as practice routines can be edited through the provided interface and saved with the Export command. These exported filed can be later Imported for re-use.
